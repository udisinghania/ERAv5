# Historical evidence

These files preserve the original experiment code, settings, results, logs and hashes. They are read-only reference snapshots. Their original machine paths and references to local best/resume checkpoints are retained as provenance; those paths are not used by the portable runner. The package's three final checkpoints are in `../checkpoints/` and `../data/Run_20M_50M_v1/checkpoints/`.

Use the top-level README, SETUP.md and run.py for executable commands. Use the top-level MANIFEST.json for relocation-safe integrity checks. Historical artifact manifests describe the original local experiment folders, including files intentionally not published here.
